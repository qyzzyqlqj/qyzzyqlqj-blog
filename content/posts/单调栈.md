在解决算法问题时，我们常遇到这类需求：**寻找数组中每个元素左侧或右侧“第一个比它大”或“第一个比它小”的元素**。

如果使用暴力双重循环，时间复杂度为 $O(N^2)$。利用**单调栈**（Monotonic Stack），我们可以将这类问题的时间复杂度优化至 $O(N)$。

---

## 一、什么是单调栈？

**单调栈**本质上是一个普通的栈，只是在入栈和出栈时遵循一个严格的规则：**栈内的元素始终保持单调递增或单调递减**。

* **单调递增栈**：从栈底到栈顶元素依次增大（用于找两侧第一个比当前元素**小**的元素）。
* **单调递减栈**：从栈底到栈顶元素依次减小（用于找两侧第一个比当前元素**大**的元素）。

> **核心思想：** 利用栈的后进先出（LIFO）特性，当新元素破坏栈的单调性时，强行弹出栈顶元素。**每一次“弹出”都意味着栈顶元素的命运被确定了**（找到了目标）。

---

## 二、模板推导思路（以“寻找右侧第一个更大的元素”为例）

很多初学者容易死记硬背单调栈的代码，其实它的代码结构是通过逻辑**自然推导**出来的。

### 1. 问题分析

假设我们要求数组中每个元素右侧第一个比它大的元素。
如果我们从左往右遍历数组，对于当前元素 $x$：

* 如果 $x$ 比栈顶元素**小**，说明 $x$ 还不能作为栈顶元素的“右侧更大值”，$x$ 暂时入栈等待。
* 如果 $x$ 比栈顶元素**大**，说明 **$x$ 正是栈顶元素在右侧遇到的第一个更大的数**！

### 2. 状态转移与弹出逻辑

一旦发现 $x > \text{栈顶}$：

1. 栈顶元素找到了它的答案（就是 $x$），将其记录下来。
2. 将栈顶元素**弹出**。
3. 继续比较新的栈顶元素与 $x$。如果 $x$ 仍然大于新栈顶，重复上述步骤，直到 $x \le \text{栈顶}$ 或栈为空。
4. 将 $x$ **压入**栈中。

### 3. 时间复杂度分析

尽管代码中有 `while` 循环，但每个元素**最多入栈一次、出栈一次**。因此，均摊时间复杂度为 **$O(N)$**。

## 三、基础模板与代码实现

### 题目来源：洛谷 P5788 【模板】单调栈

**题目**：https://www.luogu.com.cn/problem/P5788

> **题目大意：**  
> 给定一个长度为 $n$ 的数列 $a$，求每个元素右边第一个比它大的元素的**下标**（1-based）。若不存在则输出 $0$。  
> 数据规模：$1 \le n \le 3 \times 10^6$。

---

### 标准 STL 模板实现

~~~cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    vector<int> ans(n + 1, 0); // 存结果，默认全为 0
    stack<int> st;            // 存放数组下标，便于获取位置

    // 从左到右遍历每个元素
    for (int i = 1; i <= n; i++) {
        // 当栈不为空，且当前元素大于栈顶元素时
        // 意味当前元素 a[i] 就是栈顶元素右边第一个更大的数
        while (!st.empty() && a[i] > a[st.top()]) {
            ans[st.top()] = i; // 记录栈顶元素的答案为当前下标 i
            st.pop();          // 弹出已解决的栈顶
        }
        st.push(i); // 将当前元素的下标压入栈中
    }

    // 输出结果
    for (int i = 1; i <= n; i++) {
        cout << ans[i] << (i == n ? "" : " ");
    }
    cout << '\n';
}

int main() {
    // 开启 C++ I/O 加速
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
~~~

## 四、进阶应用：二维悬崖悬空/最大全 1 子矩阵

单调栈不仅能解决一维直方图问题，还可以通过**按行降维**的方式，优雅地解决二维网格图中的最大矩形问题。

### 题目来源：洛谷 P4147 玉蟾宫

**原题**：[https://www.luogu.com.cn/problem/P4147](https://www.luogu.com.cn/problem/P4147)

>   **题目大意：**
>
>   给定一个 $N \times M$ 的网格，里面只包含 `F` 和 `R` 两种字符。
>
>   求全由 `F` 构成的最大子矩形面积 $S$，并输出 $3 \times S$ 的值。
>
>   数据规模：$1 \le N, M \le 1000$。

### 解题思路与模型转换

1.  **悬高转换（降维）：**

    对于网格中的任意一行 $r$，我们可以统计每个位置连续向下（或向上）延伸的连续 `F` 长度，将其记为柱子高度 $h_j$。

    -   如果当前字符是 `F`，则 $h_j = h_j + 1$；
    -   如果当前字符是 `R`，则该位置无法构成悬高，Height 直接清零：$h_j = 0$。

2.  **化归为“直方图最大矩形”：**

    处理完第 $r$ 行的高度数组后，问题就**完全转化为“直方图中最大的矩形”**！

    遍历每一行，以该行作为底部基准线，对该行的 $h$ 数组跑一遍单调栈，更新全局最大面积 $S$。

3.  **复杂度分析：**

    对于每一行执行一次 $O(M)$ 的单调栈求解，总共 $N$ 行，总时间复杂度为 **$O(N \times M)$**，空间复杂度为 $O(M)$，可以完美通过 100% 的数据。

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> h(m + 2, 0); // 维护当前行的连续 'F' 高度数组
    int max_area = 0;

    for (int i = 1; i <= n; i++) {
        // 1. 读取当前行数据并更新连续高度
        for (int j = 1; j <= m; j++) {
            char ch;
            cin >> ch;
            if (ch == 'F') {
                h[j] += 1;
            } else {
                h[j] = 0; // 遇到 'R' 阻断，高度重置为 0
            }
        }

        // 末尾放置哨兵 0，确保遍历结束时栈内所有元素均能强行弹出结算
        h[m + 1] = 0;

        // 2. 对当前行运行单调递增栈，求解以当前行为底的最大矩形
        stack<int> st;
        for (int j = 1; j <= m + 1; j++) {
            while (!st.empty() && h[j] < h[st.top()]) {
                int height_idx = st.top();
                st.pop();

                // 确定矩形的左右边界
                int left_bound = st.empty() ? 1 : st.top() + 1;
                int right_bound = j - 1;
                int width = right_bound - left_bound + 1;

                max_area = max(max_area, h[height_idx] * width);
            }
            st.push(j);
        }
    }

    // 根据题目要求，最终答案输出 3 * S
    cout << max_area * 3 << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();

    return 0;
}
```

## 五、单调栈口诀与技巧总结

1.  **确定目标决定栈的单调性：**

    -   找“更大”用**单调递减栈**（栈顶最小，遇到大数触发弹出）。
    -   找“更小”用**单调递增栈**（栈顶最大，遇到小数触发弹出）。

2.  **存储下标而非数值：**

    栈内通常**存储数组下标**而非具体数值。下标既能用来在原数组中查值 `a[st.top()]`，又能用来直接计算位置距离 `i - st.top()`。

3.  **哨兵机制（Sentinel）：**

    在数组末尾追加一个极小/极大值（如 $0$ 或 $\infty$），可以强行触发栈内剩余所有元素的出栈逻辑，避免循环结束后还需要额外清空栈代码。
