## 一、常识问题

对于如下代码段，其时间复杂度为（ ）。 
 
```cpp
int s = 0;
for (int i = 1; i <= n; i *= 2)
    for (int j = 1; j <= i; j++)
        s++;
```
A. $O(n)$  
B. $O(n \log n)$  
C. $O(n^2)$  
D. $O(\log n)$ 

#### 【错选】：B
#### 【正解】：A
#### 【题目考点】：时间复杂度分析
#### 【错因】：没有正确理解算法时间复杂度的分析，没有带入验证盲目猜测，经验注意
### 【分析】：
* 外层循环变量 $i$ 的取值为 $1, 2, 4, 8, \dots, 2^k$（且 $2^k \le n$）。*
* 内层循环运行 $i$ 次，因此总的执行次数为 $1 + 2 + 4 + \dots + 2^k$。这是一个等比数列求和，结果为 $2^{k+1} - 1 \approx 2n$。忽略常数后，时间复杂度为 $O(n)$。

一个大小为 13 的哈希表，哈希函数为 $H(x) = x mod 13$，采用线性探查解决冲突。依次插入 18, 31, 44, 57, 70，则 70 最终存放在下标（ ）。  
   A. 7  
   B. 8  
   C. 9  
   D. 10

* 插入 70：$70 \bmod 13 = 5$，探查到空位下标 9。最终存放于下标 9。

一棵二叉搜索树的后序遍历序列为：`1 3 2 5 7 6 4`，则它的前序遍历序列为（ ）。  
   A. `4 2 1 3 6 5 7`  
   B. `4 2 3 1 6 7 5`  
   C. `1 2 3 4 5 6 7`  
   D. `4 6 5 7 2 1 3`  

#### 【错选】：B
#### 【正解】：A
#### 【题目考点】：树的遍历
#### 【错因】：对前、中、后序遍历不熟悉，考场上虽然推出来了，但是选错选项
#### 【分析】：
* 后序遍历序列 `1 3 2 5 7 6 4` 的最后一个元素 4 是根节点。
* 根据二叉搜索树性质，小于 4 的 `{1, 2, 3}` 是左子树，大于 4 的 `{5, 6, 7}` 是右子树。
* 左子树后序为 `1 3 2`，可知左子树根为 2，左孩子 1，右孩子 3。
* 右子树后序为 `5 7 6`，可知右子树根为 6，左孩子 5，右孩子 7。
* 组合后求前序遍历（根-左-右），得 `4 2 1 3 6 5 7`。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

bool ck(vector<int>& a, int x, ll k) {
    ll s = 0;
    for (int i = 0, j = 0; i < (int)a.size(); i++) {
        while (a[i] - a[j] > x) j++;
        s += i - j;
    }
    return s >= k;
}

int sol(vector<int> a, ll k) {
    sort(a.begin(), a.end());
    int l = 0, r = a.back() - a[0];
    while (l < r) {
        int m = (l + r) / 2;
        if (ck(a, m, k)) r = m;
        else l = m + 1;
    }
    return l;
}

int main() {
    int n;
    ll k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    cout << sol(a, k) << endl;
    return 0;
}
```

假设输入合法，且所有计算均不会溢出。

### 代码功能分析

* **整体作用**：该程序用于求解一个长度为 $n$ 的整数数组 $a$ 中，所有满足 $i < j$ 的两两绝对差 $|a_i - a_j|$ 中**第 $k$ 小的差值**。
* **算法核心**：
  * **二分答案**：差值的范围在 $0$ 到 `a.back() - a[0]` 之间，程序通过二分法（`sol` 函数）猜测第 $k$ 小的差值 $m$。
  * **双指针检验**：`ck` 函数对排序后的数组利用双指针（`i` 和 `j`）在线性时间内统计差值不超过 $m$ 的数对数量，从而判断当前 $m$ 是否满足条件。
* **时间复杂度**：排序的时间复杂度为 $\Theta(n \log n)$，二分查找的次数为 $\Theta(\log A)$（其中 $A$ 为最大值与最小值的差），整体时间复杂度为 $\Theta(n \log n + n \log A)$。



### 1. 当数组 `a` 已经按非降序排列时，`ck(a, x, k)` 判断的是差值不超过 $x$ 的数对数量是否至少为 $k$。（ ） 

#### 【错选】：F
#### 【正解】：T
#### 【考点】：代码部分功能理解判断
#### 【错因】：没有完全理解代码作用和实现逻辑与细节
#### 【分析】：

  * **双指针统计**：在 `ck` 函数中，当数组 `a` 已经按非降序排列时，对于每一个右端点 `i`，通过 `while (a[i] - a[j] > x) j++;` 可以找到最小的左端点 `j`，使得区间 `[j, i]` 内的所有元素与 `a[i]` 的差值均不超过 $x$。
  * **数对数量**：对于当前的 `i`，满足 $a[i] - a[j] \le x$ 的合法左端点 `j` 的数量为 $i - j$，将其累加到变量 `s` 中，即代表整个数组中差值不超过 $x$ 的数对总数。
  * **阈值判断**：最后返回 `s >= k`，用来判断差值不超过 $x$ 的数对数量是否至少为 $k$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int a[22], b[1 << 20];

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    int m = 1 << n;
    for (int s = 0; s < m; s++) {
        int c = 0, v = 0;
        for (int i = 0; i < n; i++) {
            if (s >> i & 1) {
                c++;
                v += a[i];
            }
        }
        if (c % 2) b[s] = -v;
        else b[s] = v;
    }
    sort(b, b + m);
    cout << b[0] << " " << b[m - 1] << endl;
    int t = 0;
    for (int i = 0; i < m; i++)
        if (b[i] == 0) t++;
    cout << t << endl;
    return 0;
}
```

假设 $1 \le n \le 20$，且所有 $a_i$ 均为正整数。

### 代码功能分析

* **整体作用**：该程序通过**状态压缩（二进制枚举）**遍历子集，计算数组 $a$ 的所有子集和，并在子集元素个数为奇数时取相反数、偶数时保持正号。随后对处理后的所有子集值进行排序，输出其中的**最小值**和**最大值**，并统计值为 **0** 的子集数量。
* **算法核心**：
  * **子集枚举**：通过外层循环 `s` 从 $0$ 到 $2^n - 1$，利用二进制每一位是否为 $1$ 来表示元素是否被选中。
  * **符号变换**：变量 `c` 记录选中元素的个数（子集大小），若 `c` 为奇数，则对应子集和取负（`b[s] = -v`）；若为偶数，则保持原值（`b[s] = v`）。
  * **排序与统计**：将所有 $2^n$ 个子集的结果存入数组 `b` 中并进行排序，从而可以直接输出最小值 `b[0]`、最大值 `b[m - 1]`，并统计和为 $0$ 的方案数 `t`。
* **时间复杂度**：总状态数为 $2^n$，内层循环进行 $n$ 次操作，排序的时间复杂度为 $\mathcal{O}(2^n \log(2^n)) = \mathcal{O}(n 2^n)$，因此整体时间复杂度为 $\Theta(n 2^n)$。

给定一张 $n$ 个点、$m$ 条边的无向带权图，边权均为非负整数。给定起点 $s$ 和终点 $t$。  
现在有一张折扣卡，可以在经过某一条边时使用一次，使这条边的费用变为 $\lfloor w/2 
floor$。折扣卡最多使用一次，也可以不使用。  
求从 $s$ 到 $t$ 的最小费用。

试补全程序。


```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int N = 100005;
const ll INF = (1LL << 60);

struct Ed {
    int v, w;
};

struct Sta {
    ll d;
    int u, c;
    bool operator < (const Sta& o) const {
        return ①;
    }
};

int n, m, s, t;
vector<Ed> g[N];
ll dis[N][2];

int main() {
    cin >> n >> m >> s >> t;
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    for (int i = 1; i <= n; i++)
        dis[i][0] = dis[i][1] = INF;
    
    priority_queue<Sta> q;
    ②;
    q.push({0, s, 0});
    
    while (!q.empty()) {
        Sta x = q.top();
        q.pop();
        if (③) continue;
        for (auto e : g[x.u]) {
            int v = e.v;
            int c = x.c;
            if (④ < dis[v][c]) {
                dis[v][c] = ④;
                q.push({dis[v][c], v, c});
            }
            if (!c && ⑤ < dis[v][1]) {
                dis[v][1] = ⑤;
                q.push({dis[v][1], v, 1});
            }
        }
    }
    cout << min(dis[t][0], dis[t][1]) << endl;
    return 0;
}
```

### 代码功能与结构分析

* **整体作用**：该程序用于求解带权无向图中从起点 $s$ 到终点 $t$ 的**最短路径**，并允许在整条路径中**最多使用一次折扣卡**，使某一条边的费用减半（向下取整 $\lfloor w/2 \rfloor$）。
* **算法核心**：
  * **分层图最短路（状态扩展）**：利用 Dijkstra 算法求最短路。状态结构体 `Sta` 包含三个核心要素：当前距离 `d`、当前节点 `u`、以及折扣卡使用状态 `c`（`c = 0` 表示未使用，`c = 1` 表示已使用）。
  * **优先队列优化**：使用 `priority_queue` 维护优先队列，配合重载小于号实现小根堆（每次取出距离最小的状态）。
  * **状态转移**：
    * **不使用折扣卡转移**：在当前状态卡片使用情况 `c` 保持不变的前提下，尝试松弛邻接点 `v` 的 `dis[v][c]`。
    * **使用折扣卡转移**：若当前状态未用过卡（`!c`），则可以通过当前边使用折扣卡，将状态转移至 `c = 1`，更新 `dis[v][1]`。
* **时间复杂度**：图中的每个节点有两种状态（卡片用或没用），总状态数为 $2n$，边数为 $m$。使用优先队列优化的 Dijkstra 算法时间复杂度为 $\mathcal{O}((n + m) \log n)$。


 ③ 处应填（ ）。  
    A. `x.d == dis[x.u][x.c]`  
    B. `x.d != dis[x.u][x.c]`  
    C. `x.u == t`  
    D. `x.c == 1`  

#### 【错选】：C
#### 【正解】：B
#### 【考点】：代码部分功能理解判断、迪杰斯特拉
#### 【错因】：没有完全理解状态转移过程
#### 【分析】：
* 这是 Dijkstra 优先队列的一个经典“懒惰删除”判定。当取出的距离 `x.d` 大于当前记录的最小距离 `dis[x.u][x.c]`（或直接使用不等于 `!=` 进行比较，因为入队只有更小才会进），代表这个状态已经被更优的路径覆盖，无需再拓展。故选 `x.d != dis[x.u][x.c]`。
