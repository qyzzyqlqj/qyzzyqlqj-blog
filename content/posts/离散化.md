在程序设计竞赛与实际算法开发中，我们经常遇到这类问题：**数据的范围极大（如 $-10^9 \sim 10^9$），但数据的实际数量 $N$ 却相对较小（如 $N \le 10^5$）**。

如果直接使用数组下标记录数据，会导致内存超限（MLE）；如果直接用数据原始值，也无法将它们作为标准数据结构（如树状数组、线段树）的索引。这时就需要用到**离散化**技术。

---

## 一、什么是离散化？

**离散化**，通俗来说就是**将“大而稀疏”的数据序列映射到“小而连续”的合理数值区间**，同时完好保留原数据之间的大小相对关系。

> **核心思想：** 不关注数值本身的大小，只关注该数值在所有不同数值中的**相对排名**。

---

## 二、常见实现方式对比

| 实现方式 | 核心机制 | 性能与特点 | 推荐度 |
| :--- | :--- | :--- | :--- |
| **排序 + 二分查找** | `std::sort` + `std::unique` + `std::lower_bound` | **代码精简，性能最优**，时间复杂度 $O(N \log N)$ | 极力推荐 |
| **哈希表映射** | `std::unordered_map` | 思路直观，但有较大的常数开销，且存在哈希冲突风险 | 一般 |
| **结构体排序** | 记录原始下标与数值，排序后重新赋予新连续索引 | 适用于无需去重或特定顺序要求的特殊场景 | 按需选用 |

---

## 三、基础模板与代码实现

### 题目来源：洛谷 B3694 【模板】数列离散化

**原题** ：https://www.luogu.com.cn/problem/B3694

> **题目大意：**  
> 给定一个长度为 $n$ 的数列 $a$，求每个元素 $a_i$ 离散化后的排名 $\mathrm{rank}(i)$（相同数值排名相同，排名从 $1$ 开始）。  
> 数据规模：$1 \le n \le 10^5$，$ -10^9 \le a_i \le 10^9$。

---

### 方法一：标准 STL 模板（排序 + 去重 + 二分定位）

这是比赛和日常开发中最常用、最稳妥的标准写法。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // 1. 复制原数组并进行 排序 + 去重，建立有序映射轴
    vector<int> a = arr;
    sort(a.begin(), a.end());
    // unique 将重复元素移动到末尾，erase 将其彻底剔除
    a.erase(unique(a.begin(), a.end()), a.end());

    // 2. 利用 std::lower_bound 快速二分定位排名
    for (int i = 0; i < n; i++) {
        // lower_bound 返回指向第一个 >= arr[i] 元素的迭代器
        // 减去 a.begin() 得到 0-based 排名，+1 转换为 1-based 排名
        arr[i] = lower_bound(a.begin(), a.end(), arr[i]) - a.begin() + 1;
    }

    // 3. 输出离散化后的结果
    for (int i = 0; i < n; i++) {
        cout << arr[i] << (i == n - 1 ? "" : " ");
    }
    cout << '\n';
}

int main() {
    // 开启 C++ I/O 加速
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        solve();
    }

    return 0;
}

```

### 方法二：哈希表映射法（便于理解映射过程）

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;

    // mp 用于记录“每个数值”在原数组中出现的原始下标列表
    unordered_map<int, vector<int>> mp;
    vector<int> arr(n);

    for (int i = 0; i < n; i++) {
        cin >> arr[i];
        mp[arr[i]].push_back(i); // 记录数值出现的位置
    }

    // 排序 + 去重
    vector<int> a = arr;
    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());

    // 按排序后的顺序，将新排名回填给原下标
    for (size_t i = 0; i < a.size(); i++) {
        for (int idx : mp[a[i]]) {
            arr[idx] = i + 1; // 1-based 排名
        }
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << (i == n - 1 ? "" : " ");
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        solve();
    }

    return 0;
}

```

## 四、进阶应用：二维坐标离散化与覆盖面积计算

离散化不单能用于一维数组降维，在计算几何与网格图问题中，离散化经常与**二维差分 / 扫描线**结合，用于处理大范围的图形覆盖与面积统计。

### 题目来源：P1884 [USACO12FEB] Overplanting S

**原题** ：https://www.luogu.com.cn/problem/P1884

> **题目大意：**
> 在平面直角坐标系中，给定 $N$ ($1 \le N \le 1000$) 个矩形的左上角和右下角坐标，坐标范围在 $[-10^8, 10^8]$。
> 求这 $N$ 个矩形覆盖的总面积（重叠部分只计算一次）。

---

### 解题思路

坐标范围达到 $10^8$，直接建立网格必定内存超限。但矩形数量最多只有 $1000$ 个，这意味着所有矩形在 $X$ 轴和 $Y$ 轴上产生的关键分割线分别最多只有 $2000$ 条。

1. **收集坐标：** 将所有矩形的左/右、上/下边界坐标分别存入数组进行离散化。
2. **分割网格：** 离散化后的坐标将整个平面划分成一系列小网格。
3. **二维差分：** 对每个矩形对应的网格区域进行打标。
4. **面积累加：** 统计被至少一个矩形覆盖的网格，累加其真实物理面积：

$$\text{Area} = (x_{i+1} - x_i) \times (y_{j+1} - y_j)$$



```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> xa(n), ya(n), xb(n), yb(n);
    vector<int> xc, yc;

    for (int i = 0; i < n; i++) {
        cin >> xa[i] >> ya[i] >> xb[i] >> yb[i];
        // 收集所有 X 和 Y 坐标值用于轴离散化
        xc.push_back(xa[i]);
        xc.push_back(xb[i]);
        yc.push_back(ya[i]);
        yc.push_back(yb[i]);
    }

    // 1. X 轴与 Y 轴坐标分别排序并去重
    sort(xc.begin(), xc.end());
    xc.erase(unique(xc.begin(), xc.end()), xc.end());

    sort(yc.begin(), yc.end());
    yc.erase(unique(yc.begin(), yc.end()), yc.end());

    // 2. 构建网格二维差分数组 d
    int nx = xc.size(), ny = yc.size();
    vector<vector<int>> d(nx + 2, vector<int>(ny + 2, 0));

    // 3. 将每个矩形映射到离散坐标轴上并打上二维差分标记
    for (int i = 0; i < n; i++) {
        int X1 = lower_bound(xc.begin(), xc.end(), xa[i]) - xc.begin();
        int X2 = lower_bound(xc.begin(), xc.end(), xb[i]) - xc.begin();
        int Y1 = lower_bound(yc.begin(), yc.end(), ya[i]) - yc.begin();
        int Y2 = lower_bound(yc.begin(), yc.end(), yb[i]) - yc.begin();

        if (X1 > X2) swap(X1, X2);
        if (Y1 > Y2) swap(Y1, Y2);

        // 在离散网格区间 [X1, X2) x [Y1, Y2) 上施加 +1 操作
        d[X1][Y1] += 1;
        d[X1][Y2] -= 1;
        d[X2][Y1] -= 1;
        d[X2][Y2] += 1;
    }

    ll total_area = 0;

    // 4. 通过二维前缀和还原各网格覆盖状态，并计算真实面积
    for (int i = 0; i < nx - 1; i++) {
        for (int j = 0; j < ny - 1; j++) {
            if (i > 0) d[i][j] += d[i - 1][j];
            if (j > 0) d[i][j] += d[i][j - 1];
            if (i > 0 && j > 0) d[i][j] -= d[i - 1][j - 1];

            // 若当前网格块被至少一个矩形覆盖
            if (d[i][j] > 0) {
                ll width = xc[i + 1] - xc[i];
                ll height = yc[j + 1] - yc[j];
                total_area += width * height;
            }
        }
    }

    cout << total_area << "\n";

    return 0;
}

```

## 五、开发细节与注意事项

1. **`unique` 函数的前提条件：**
使用 `std::unique` 去重前**必须先进行排序**。因为 `unique` 只会剔除连续的重复元素。
2. **必须配合 `.erase()` 清理内存：**
`std::unique` 并不改变容器的底层物理大小，它只是将重复元素移至容器末尾并返回新界限的迭代器。必须显式调用 `erase` 才能真正缩减容器尺寸。
3. **网格“点转面”映射边界：**
在几何离散化中，离散点 $xc[i]$ 与 $xc[i+1]$ 之间代表一个**线段/面**区间，在计算遍历时控制上限为 `size - 1`，防止访问越界。
